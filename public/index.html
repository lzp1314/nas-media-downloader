磁力搜索源

检测中

搜索地址写在 config/magnet-sources.json（容器内为 /config/magnet-sources.json），不进仓库、不进镜像。 直接填站点首页也行，程序会自己找搜索表单、跟随跳转、抓详情页里的磁力；改完无需重启。

豆瓣（可选）

未设置

只用来补「总集数 / 别名 / 首播日」，不搜资源，也不影响能不能补到集。不填也能用，只是集数偶尔不准。

拿法：浏览器登录豆瓣 → 按 F12 → 打开 Network（网络）→ 刷新页面 → 点任意一个请求 → 在 Request Headers 里找到 Cookie: 整行，把后面那串复制过来（以 dbcl2= 开头那种）。 只存在 NAS 的配置目录里，保存后界面上不再回显。

TMDB（推荐）

未设置

给的是逐集登记过的剧集数据：总集数、别名，以及下一集哪天播。 填了它，订阅里连更新日都不用挑——程序按播出日历自己排。

密钥自己申请：登录 themoviedb.org → 右上头像 → Settings → API → 新建，拿到 「API 密钥（v3，32 位）」或「API 读访问令牌（v4，eyJ 开头）」，两个填一个就行， 两个都填以令牌为准。密钥只存在 NAS 的配置目录里，保存后界面上不再回显。

下载目录绑定

只能写进容器挂载的目录里。这里列出的文件夹，会在下载时作为快捷选项。compose 里新增一行挂载并重建容器后会自动出现在这里；手动移除过的目录不会再自动加回。
